## Methodology

### Test Infrastructure

- **Framework:** JUnit 5 (not JMH - follows Delos pattern)
- **Timing:** Manual System.nanoTime() measurement with warmup/measurement iterations
- **Warmup:** 50 iterations (50 for large_tests)
- **Measurement:** 200 iterations (500 for large_tests)
- **Throughput:** 5-second duration (10 seconds for large_tests)
- **Determinism:** SeededSecureRandom for reproducible test data

### Test Modes

**Standard Mode** (default):
```bash
./mvnw test -pl thoth -Dtest=PerformanceBaselineTest
```
- 5-node cluster
- 200 measurement iterations
- 5-second throughput tests
- Fast feedback (~2-3 minutes)

**Large Tests Mode** (thorough):
```bash
./mvnw test -pl thoth -Dtest=PerformanceBaselineTest -Dlarge_tests=true
```
- 10-node cluster
- 500 measurement iterations
- 10-second throughput tests
- Comprehensive measurement (~10-15 minutes)

### Metrics Overhead Measurement

Measures performance impact of Micrometer metrics:

1. **With Metrics:** Uses MicrometerKerlDhtMetrics
2. **Without Metrics:** Uses KerlDhtMetrics.noOp()
3. **Overhead:** `((with - without) / without) * 100%`
4. **Target:** <5% overhead acceptable
