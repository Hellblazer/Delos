REMEMBER: CORE PRINCIPLE
================================================================================

TEST-FIRST FOR SECURITY

1. Write failing test demonstrating vulnerability
2. Test runs but fails (shows vulnerability exists)
3. Implement minimal fix
4. Test passes (shows fix addresses vulnerability)
5. Run full regression suite (shows no new problems)
6. Document learning

Why this works:
  - Vulnerabilities must be reproducible
  - Fixes must be minimal and targeted
  - No over-engineering or scope creep
  - Evidence is captured for security audit
